# The Logic Ledger — DSA Tracker

A clean, persistent progress tracker for Striver’s A2Z DSA Course. Track 400+ topics with a minimal, distraction-free interface.

---


## Features

- Persistent checkboxes using localStorage
- Live progress statistics with completion percentage
- Daily tracking to monitor consistency
- Search and filter topics quickly
- Instant interaction feedback
- Notes section for personal learning
- Minimal UI without unnecessary layers

---

## Approach

- Topics are displayed in a flat list
- Each topic links directly to the original Striver resource
- No nested step-based structure
